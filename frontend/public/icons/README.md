# PWA 图标说明

## 所需图标尺寸

请生成以下尺寸的 PNG 图标并放入此目录：

- `icon-72x72.png` - 通知徽章
- `icon-96x96.png` - 通用
- `icon-128x128.png` - 通用
- `icon-144x144.png` - 通用
- `icon-152x152.png` - iOS
- `icon-192x192.png` - Android 主屏幕
- `icon-384x384.png` - 通用
- `icon-512x512.png` - 通用

## 图标要求

- 格式：PNG（透明背景）
- 风格：简洁、易识别
- 建议：使用品牌 Logo 或代表性图案

## 快速生成工具

可以使用以下工具生成所有尺寸：

1. **RealFaviconGenerator**: https://realfavicongenerator.net/
2. **PWA Icon Generator**: https://app-manifest.firebaseapp.com/
3. **Figma/Sketch**: 导出多个尺寸

## 快捷方式图标

- `shortcut-write.png` - 写日记快捷方式 (96x96)
- `shortcut-dashboard.png` - 数据看板快捷方式 (96x96)

## 截图

为 manifest.json 添加应用截图（可选但推荐）：

- `screenshots/home.png` - 首页截图 (1080x1920)
- `screenshots/dashboard.png` - 数据看板截图 (1080x1920)
