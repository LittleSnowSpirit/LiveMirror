# LiveMirror — 产品功能说明

## 产品定位

AI 驱动的直播复盘分析平台。面向个人主播和运营团队，帮助他们通过数据洞察提升直播效果。产品形态为 PWA（可安装到手机桌面的 Web 应用），移动端优先，同时支持桌面端响应式布局。

---

## 现有功能

### 一、用户体系

- 账号注册与登录（JWT 令牌认证）
- 个人中心：查看个人资料、头像、简介
- 配额与用量管理：每周免费分析次数限制，用量统计，下次重置时间提醒
- 主题切换：支持亮色 / 暗色模式

### 二、直播内容输入

- **音视频上传**：上传本地音频或视频文件，系统自动进行语音转写（支持 Whisper 引擎）
- **链接解析**：粘贴直播回放链接，系统自动下载音频并分析，支持主流直播平台
- 上传任务状态追踪：显示处理进度（转写中 → 分析中 → 完成），实时进度反馈

### 三、AI 智能分析（核心能力）

系统对转写文本进行多维度 AI 分析，能力包括：

- **话术分段**：自动将直播转写稿按时间段切分为话术片段
- **话术分类**：识别每段话术的类型（开场白、产品介绍、价格促销、限时抢购、促单成交、收尾等）
- **情绪曲线分析**：追踪整场直播的情绪波动曲线，识别情绪高峰和低谷
- **节奏分析**：评估各段话术的时长是否合理，发现节奏问题
- **互动指标评估**：分析话术中的互动引导元素是否充足
- **话术多样性分析**：评估主播话术的丰富程度和变化
- **爆点识别**：找出直播中表现出色的话术高光时刻
- **翻车点识别**：发现可能导致观众流失的话术问题

### 四、分析报告

- 综合得分：对整场直播给出量化评分
- 摘要总结：一句话概括本场直播的核心表现
- 话术片段详情：每段话术的内容、时间、分类、表现评分
- 优化建议列表：按优先级排序的具体改进建议，包含问题描述和参考改写
- 执行摘要：可快速阅读的精华版报告

### 五、话术归因分析

- **话术-情绪关联**：分析哪些话术引发了情绪峰值，建立因果关系
- **话术-弹幕关联**：分析哪些话术引发了观众互动爆发（弹幕密度、情感倾向）
- **综合评分排名**：按影响力对所有话术片段排序，找出 Top N 最有效和最无效的话术
- **归因置信度**：每条归因结果附带置信度说明，基于数据充分度评估
- 三维关联可视化：话术 × 情绪 × 弹幕的时间轴对齐展示

### 六、话术优化建议引擎

- **问题诊断**：从节奏、情感表达、互动元素、关键词使用、逻辑结构五个维度诊断话术问题
- **严重程度分级**：每个问题标注高 / 中 / 低优先级
- **Before / After 改写示例**：展示原始话术和优化后的改写对比
- **预期提升效果**：量化预估改进幅度（如情绪影响 +15~25%）
- **优秀话术推荐**：从数据库中推荐同类话术的高分范例

### 七、弹幕分析

- **弹幕数据导入**：支持上传弹幕文件（JSON / CSV 格式），批量解析入库
- **弹幕情感分析**：自动对每条弹幕进行积极 / 消极 / 中性情感分类和打分
- **情感曲线**：按时间窗口聚合弹幕情感趋势折线图
- **关键词云 / 词频统计**：提取弹幕中的高频关键词，标注主流情感倾向
- **高光时刻**：自动识别弹幕密度最高的时间段
- **互动指标**：弹幕密度（条/分钟）、情感波动率、情感分布比例
- **话术-弹幕时间对齐**：将弹幕时间线与转写文本对齐，分析哪些话术引发了什么弹幕反应
- **时滞分析**：计算话术到弹幕反应的时间差

### 八、趋势洞察

- **多场次历史对比**：横向比较多场直播的各项指标变化
- **情绪趋势**：追踪情绪调动能力的变化趋势（上升 / 下降 / 平稳）
- **互动趋势**：追踪观众互动率的变化
- **话术质量趋势**：按话术类型（开场白、产品介绍等）分别追踪质量变化
- **显著变化检测**：自动发现指标的大幅波动点
- **成长报告**：综合所有维度，生成阶段性成长总结，包含 Top 进步项、待改进项和针对性建议

### 九、报告导出与分享

- **多格式导出**：支持 JSON、Markdown 格式导出
- **PDF 报告**：生成结构化 PDF 报告，支持多种模板（精简版 / 详细版 / 数据版）
- **批量导出**：一次性导出多个任务的报告，打包为 ZIP 文件
- **分享链接**：生成带访问码的报告分享链接，无需登录即可查看
- **分享统计**：查看分享链接的访问次数

### 十、历史记录

- 分页浏览所有历史分析任务
- 按状态筛选（处理中 / 已完成 / 失败）
- 搜索文件名
- 快捷操作：查看报告、删除任务、批量导出

### 十一、竞品监控

- **竞品管理**：添加和移除竞品直播间（支持多平台：抖音、快手、淘宝等）
- **实时数据监控**：追踪竞品直播间的观众数、点赞数、评论数、成交额、平均观看时长等
- **异常告警**：自定义告警规则（流量突增、成交额突破阈值等），触发实时告警
- **话术监控**：捕获竞品直播话术，与己方话术进行相似度对比，发现疑似抄袭
- **告警历史查询**：查看历史告警记录，按类型、时间、竞品筛选
- **通知渠道配置**：支持邮件和企业微信两种告警通知方式

### 十二、通知中心

- **站内通知**：系统事件产生的通知消息列表（分析完成、配额提醒、竞品告警等）
- **未读计数**：实时显示未读通知数量
- **WebSocket 实时推送**：新通知自动推送到前端
- **Web Push**：支持浏览器推送通知（即使未打开页面也能收到提醒）
- **通知操作**：标记已读、全部已读、删除

## 规划中的功能

### 一、商业化与计费

- 按量付费系统：按分析次数或时长收费
- 用量统计与账单
- 充值与套餐管理
- 不同等级用户的配额差异

### 二、多直播间管理

- 用户可注册和管理多个直播间
- 每个直播间独立的分析数据
- 跨直播间的综合对比看板

### 三、实时直播分析

- 直播进行中的实时数据分析
- 弹幕情绪实时监测和预警
- 话术实时提醒和优化建议

### 四、第三方数据接入

- 对接直播平台 API 获取直播数据（抖音、快手、淘宝）
- 数据自动同步和增量更新
- 减少手动上传的操作

### 五、ROI 分析（投入产出比）

- 直播成本模板管理
- 投入产出比计算和报告
- 多场 ROI 趋势对比

### 六、脚本策划

- 直播脚本模板库
- 产品话术编排
- 直播流程时间线规划

### 七、标题优化

- 直播标题关键词分析
- A/B 测试：对比不同标题的点击表现
- 标题模板推荐
- 历史标题效果回溯

### 八、敏感词检测

- 行业敏感词包管理
- 话术内容合规性检查
- 风险话术预警

### 九、报告模板自定义

- 用户可自定义报告的展示内容和布局
- 品牌 Logo 和配色定制
- 团队协作分享

### 十、移动端增强

- PWA Service Worker 离线缓存
- 可安装到手机桌面
- 移动端专属交互优化

## 数据维度速查

以下是平台会采集和分析的核心数据维度，供设计数据展示时参考：

| 维度 | 说明 |
|------|------|
| 情绪分数 | -1.0 到 1.0，表示消极到积极 |
| 话术类型 | 开场白、产品介绍、价格促销、限时抢购、促单成交、收尾 |
| 弹幕情感 | positive / negative / neutral，附带分数 |
| 弹幕类型 | 普通、高亮、争议、提问、赞赏 |
| 综合得分 | 0-100，整场直播的量化评分 |
| 互动率 | 每分钟弹幕数 |
| 话术时长 | 秒，与理想时长对比 |
| 趋势方向 | 上升 / 下降 / 平稳，附带变化幅度百分比 |
| 归因置信度 | 0-1，基于数据充分度 |
| 竞品指标 | 观众数、点赞数、评论数、成交额、平均观看时长 |
