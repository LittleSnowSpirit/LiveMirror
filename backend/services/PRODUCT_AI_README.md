# LiveMirror 智能选品 2.0 - AI 驱动选品决策系统

## 📋 功能概述

智能选品 2.0 是一个 AI 驱动的产品选择与决策分析系统，通过多维度评分、竞品分析、趋势预测、供应链风险评估和利润空间分析，帮助商家做出科学的选品决策。

## 🎯 核心功能

### 1. AI 选品评分（多维度分析）

**评分维度：**
- **市场热度 (30%)** - 基于销量、增长率、用户评分
- **竞争程度 (20%)** - 市场竞争激烈程度（分数越高竞争越小）
- **趋势评分 (20%)** - 市场趋势和增长潜力
- **供应链风险 (15%)** - 供应稳定性、供应商数量、库存周转
- **利润空间 (15%)** - 利润率和成本结构

**推荐等级：**
- 强烈推荐 (≥80 分)
- 推荐 (65-79 分)
- 谨慎考虑 (50-64 分)
- 不推荐 (<50 分)

### 2. 竞品选品分析

**分析内容：**
- 同类产品数量统计
- 平均竞争对手价格/销量
- 价格优势分析
- 销售位置比率
- 市场份额估算
- 竞争强度评估（高/中/低）
- TOP5 竞争对手详情

### 3. 趋势预测（季节性/热点）

**预测功能：**
- 未来 1-12 个月趋势预测
- 季节性因子分析
- 类别趋势变化（30 天/90 天）
- 趋势展望（乐观/平稳/谨慎）
- 热门关键词推荐（按增长率排序）
- 季节性峰值月份识别

### 4. 供应链风险评估

**风险维度：**
- 供应稳定性风险
- 供应商数量风险
- 库存周转风险
- 退货率风险

**风险等级：**
- 低风险 (≥80 分) - 绿色
- 中风险 (60-79 分) - 黄色
- 高风险 (40-59 分) - 橙色
- 极高风险 (<40 分) - 红色

**风险因素识别与优化建议**

### 5. 利润空间分析

**分析内容：**
- 销售价格 vs 产品成本
- 毛利润与毛利率
- 净利润与净利率
- 成本结构分解：
  - 产品成本
  - 平台佣金 (5%)
  - 物流成本 (8%)
  - 营销成本 (10%)
- 利润评级（优秀/良好/一般/较差）
- 月利润潜力估算
- 盈亏平衡分析
- 利润优化建议

### 6. 选品决策报告

**报告内容：**
- 产品基本信息
- 综合评分与评分明细
- 竞品分析结果
- 趋势预测结果
- 供应链风险评估
- 利润空间分析
- 决策因素（正面/负面/中性）
- 最终决策建议（强烈推荐/推荐/谨慎推荐/不推荐）
- 置信度评估（高/中高/中/低）
- 关键洞察

## 🔌 API 接口

### 基础信息
- `GET /api/product-ai/health` - 健康检查
- `GET /api/product-ai/categories` - 获取所有产品类别
- `GET /api/product-ai/product/{product_id}` - 获取产品详情

### 核心功能
- `POST /api/product-ai/score/product` - 产品评分
- `POST /api/product-ai/analyze/competitors` - 竞品分析
- `POST /api/product-ai/predict/trend` - 趋势预测
- `POST /api/product-ai/assess/supply-risk` - 供应链风险评估
- `POST /api/product-ai/analyze/profit` - 利润分析
- `POST /api/product-ai/report/decision` - 生成决策报告
- `POST /api/product-ai/top/products` - 获取 TOP 产品榜
- `GET /api/product-ai/batch/score` - 批量产品评分

### 请求示例

#### 产品评分
```json
POST /api/product-ai/score/product
{
  "product_id": "P1001"
}
```

#### 趋势预测
```json
POST /api/product-ai/predict/trend
{
  "category": "美妆",
  "months_ahead": 3
}
```

#### 决策报告
```json
POST /api/product-ai/report/decision
{
  "product_id": "P1001"
}
```

```json
      "market_score": 78.2,

```

## 📊 使用场景

### 场景 1：新品选品

3. 识别薄弱环节
4. 参考优化建议
5. 制定改进计划

### 场景 3：市场趋势分析
1. 选择产品类别
2. 查看趋势预测
3. 分析季节性因素
4. 关注热门关键词
5. 调整选品策略

### 场景 4：供应链优化
1. 评估供应链风险
2. 查看风险因素
3. 执行优化建议
