## 推荐算法

综合推荐分数计算公式：
```
score = (
  heat_score * 0.30 +          # 热度分数 30%
  profit_score * 0.25 +        # 利润分数 25%
  seasonality_score * 0.20 +   # 季节性 20%
  supplier_score * 0.15 +      # 供应商 15%
  price_advantage * 0.10       # 价格优势 10%
)
```

推荐等级：
- **>= 80**: 强烈推荐 (Strong Recommend)
- **>= 60**: 推荐考虑 (Consider)
- **< 60**: 谨慎选择 (Caution)
